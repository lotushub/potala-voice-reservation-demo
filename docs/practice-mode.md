# Public practice mode

The public page offers a browser-only booking simulation before the optional live Vapi voice demo.

- No keys, Vapi calls, Make runs or Google Calendar writes in practice mode.
- Each visitor has separate localStorage bookings in their own browser.
- Required fictional name and phone, 1–4 guests, 90-minute events, 15 local simulated tables.
- Opening start-time rules and future dates match the demo schedule.
- Review and confirm before saving. An eight-character reference identifies each local booking.
- Change using reference, or saved phone when reference is absent. Exactly one match required. An incorrect reference does not fall back to phone.
- Reset clears this browser's practice records only. Use fictional data.

Live voice remains separate and still requires valid Vapi settings and provider credits, plus active Make scenarios for calendar actions. Practice mode is not an AI voice replacement or proof of real calendar availability.

Public demo: https://potala-voice-demo-2026.ochrescout3.chatgpt.site/#practice
